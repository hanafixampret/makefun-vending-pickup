One pickup line, written as a vending machine would say it to a passing human, for the [make.fun bounty](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee).

> I've held this chocolate hostage all day. Press my button and I'll drop everything for you.

`main.ts` (Node 22, stdlib-only) writes the line to `/output/entry.txt`, validating the 1–200 character gate and a round-trip read-back.
